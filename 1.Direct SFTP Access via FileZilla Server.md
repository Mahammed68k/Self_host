## ⚡ Prerequisites & Power Management

To allow continuous 24/7 remote file access, your host machine must remain powered on and connected to your network.

### 1. Power Plan Configuration
* Press `Win + R`, type `powercfg.cpl`, and press **Enter**.
* Click **Change plan settings** next to your active power plan.
* Set **Put the computer to sleep** to **Never** when *Plugged in*.
* Click **Save changes**.

### 2. Closed-Lid Operation
* In `powercfg.cpl`, click **Choose what closing the lid does** in the left sidebar.
* Under *When I close the lid*, set *Plugged in* to **Do nothing**.
* Click **Save changes**.

> ⚠️ **Thermal Caution:** Ensure your laptop is placed on a hard, well-ventilated surface or cooling pad to prevent thermal throttling during continuous operation.

### Step 1: Establish Tailscale Mesh VPN Node
  1. Install [Tailscale](https://tailscale.com/download) on your laptop and log in.   
  2. Note your laptop's Tailscale IPv4 address (formatted as `100.x.y.z`).   
  3. Install [Tailscale](https://tailscale.com/download) on your mobile device and toggle the connection to ON.

### Step 2: Install & Configure FileZilla SFTP Service
  1. Download [FileZilla Server](https://filezilla-project.org/download.php?type=server) from the official website and complete the standard installation wizard using the standard administrative options.
  2. Open the FileZilla Server Administration interface.
  3. Navigate to Server > Configure > Users.
  4. Click Add to create a new user account, and define a strong authentication password under credentials.
  5. Verification: The created user will appear in the active user list on the configuration window, and you can click Connect to FileZilla Server without receiving error messages.    

### Step 3: Mount File System Drives  
  1. Under the created user's settings, navigate to Mount points.
  2. Click Add and configure the drive mapping:
     1. Virtual Path: Set this to `/`.
     2. Native Path: Set this to `D:\` or `C:\` (to expose full operating system partitions), or map it to the specific target folder path where your 500 GB storage resides.
  3. Grant permissions by enabling Read, Write, Create, and Delete.
  4. Click OK and apply the configuration.
  5. Verification: Ensure the native path points directly to your target directory on the host machine.

⚠️ **Security Note:** Mapping root `C:\` grants full read/write access to system directories (e.g., `C:\Windows`, `C:\Program Files`). For safer operation, map the Native Path directly to your secondary partition (`D:\`) or a specific data directory (e.g., `D:\PersonalCloud`).

### Step 4: Configure Windows Defender Firewall Rules
1. Open Windows Defender Firewall with Advanced Security.
2. Create a new Inbound Rule for Port 21 (FTP) or Port 22 (SFTP), and set the action to Allow the connection.
3. Alternatively, open PowerShell as Administrator and execute the following command to allow SFTP traffic through Windows Defender Firewall:  
```powershell
New-NetFirewallRule -Name "Allow_FileZilla_SFTP" `
                    -DisplayName "FileZilla SFTP Server (Port 22)" `
                    -Direction Inbound `
                    -Protocol TCP `
                    -LocalPort 22 `
                    -Action Allow
```
Verification: Run `netstat -an | findstr 22` in Command Prompt to confirm the port is actively listening.
### Step 5: Authenticate via Mobile Client
1. Install an FTP/SFTP-compatible file management client on your mobile device or remote PC (such as [Solid Explorer](https://play.google.com/store/apps/details?id=pl.solidexplorer2), [CX File Explorer](https://play.google.com/store/apps/details?id=com.cxinventor.file.explorer), or [FileZilla Client](https://filezilla-project.org/download.php?type=client)).
2. Add a new SFTP / SSH Server Connection with the following connection properties:
   * **Host:** `100.x.y.z` (Your Tailscale IPv4 Address)
   * **Port:** `22`
   * **Username:** The configured FileZilla user
   * **Password:** The configured password
3. Save the configuration and connect.
4. **Verification:** Upload a small test file from your remote device to check if it appears in your laptop's folder.
